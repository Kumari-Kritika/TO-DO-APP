# 📝 To-Do App

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript. This app helps users manage daily tasks efficiently by allowing them to add, delete, and track tasks.

---

##  Overview

The To-Do App is designed to improve productivity by organizing tasks in a simple and user-friendly interface. It allows users to keep track of their daily activities and manage them effectively.

---

##  Features

- Add new tasks  
- Delete tasks  
- Mark tasks as completed  
- Responsive and clean UI  
- Instant updates without page reload  

---

##  Technologies Used

- HTML5 – Structure  
- CSS3 – Styling and layout  
- JavaScript – Functionality and interactivity  

---

##  How to Use

1. Enter your task in the input field  
2. Click on "Add" button  
3. View your task in the list  
4. Mark tasks as completed when done  
5. Delete tasks if no longer needed
